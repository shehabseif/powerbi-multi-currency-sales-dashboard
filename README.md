# Power BI Multi-Currency Sales Dashboard (Practice Project)

This is a Power BI practice dashboard built to demonstrate core BI skills such as data cleaning, basic modeling, DAX measures, and interactive filtering.

## What this dashboard shows

- Total sales amount (all time)
- Total sales for last month
- Monthly sales trend
- Sales amount in selected currency vs all currencies
- Products sold by country (map)
- Sales comparison for:
  - Previous 1 month
  - Previous 3 months
  - Previous 6 months
- Interactive filters for:
  - Users
  - Currency
  - Sales Territory
- Report execution timestamp

---

## Dataset

The dataset is provided as an Excel file and contains:

- fact_InternetSales
- dim_Customer
- dim_Product
- dim_Currency
- dim_SalesTerritory

---

## What I did

- Imported the dataset into Power BI
- Cleaned and prepared the data using Power Query
- Built relationships between fact and dimension tables
- Created DAX measures for KPIs and time-based comparisons
- Designed an interactive dashboard layout
- Added filters, timeline slicer, and a map visual
